## dachshund 0.1.20

This release makes shared memory attributable by default and gives every
connected agent a clearer path to recall it before answering.

### Added

- MCP writes now retain the calling agent through
  `DACHSHUND_CLIENT_AGENT`. Identical content from another agent attaches a
  second source instead of creating a duplicate memory.
- MCP initialization and managed instruction blocks now tell supported agents
  to request shared context when prior preferences, decisions, project facts,
  or lessons could affect an answer.
- Memory details now include an explicit **Share** action that promotes an
  imported memory into a dachshund-owned copy without changing the original
  agent file.
- The selected memory category now carries into agent views, making the same
  category comparable across agent-native memory models.

### Improved

- Pulse now distinguishes shared memories from source-only memories using the
  same vocabulary as the library.
- The native macOS status item uses the higher-resolution template asset at a
  smaller rendered size for a cleaner menu bar mark.
- Documentation, screenshots, and both website languages now describe MCP write
  provenance, exact-content merging, and explicit sharing.

### Removed

- Removed the outdated Windsurf integration and stale agent records. Local
  discovery now prunes agents that are no longer present in the current
  registry.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
