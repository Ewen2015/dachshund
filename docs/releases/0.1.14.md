## dachshund 0.1.14

Memory details now open into a full-window reading view, and dachshund behaves
as a menu bar utility with no Dock icon.

### Added

- Expand any memory from the right-side inspector into a full-window reader.
- Open compact-panel memories in the full app with an explicit affordance.
- Keep `Escape` progressive: collapse the reader first, then close the inspector.

### Improved

- The packaged app declares `LSUIElement`, so it stays out of the Dock and
  `Cmd+Tab`; development builds hide the Electron Dock icon at launch.
- The site hero now extends to the right edge on wide displays and keeps its
  floating memory cards fully visible.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
