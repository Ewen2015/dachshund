## dachshund 0.1.24

This release merges Claude Code and Claude Desktop into one **Claude** agent, so
both local surfaces share a single card, importer, memory model, and connection.

### Added

- One Claude importer reads Claude Code project memory, `CLAUDE.md`, rules, and
  global memory alongside Desktop Cowork Space, account, and agent topics.
- Connect now writes dachshund's MCP entry into every installed Claude surface
  and reports the card connected only when all of them are configured.
- A merged Claude memory diagram shows the two local scopes side by side and
  marks account Chat memory as cloud-only.

### Improved

- Existing `claude-code` and `claude-desktop` records, library frontmatter, and
  source identities migrate automatically to `claude`, so a rescan does not
  duplicate memories.
- Surface provenance stays visible through the `claude-code` and
  `claude-desktop` source tags.
- A Desktop-only Mac connects without creating `~/.claude.json` or a
  `CLAUDE.md` instruction block that belongs to Claude Code.
- The fixed taxonomy now has 13 agent models; the Guide, Agents, Connectors,
  README files, research notes, and both websites use the merged identity.

### Verified

- Type checks, agent and sync fixtures, MCP integration, production build, demo
  seeding, and screenshot capture pass.
- On a clone of a real library, 5 Claude Code and 1 Claude Desktop sources
  migrated to 6 Claude sources, and a rescan reported zero additions.
- Fake-home Connect tests wrote both full-install configs and only the Desktop
  config on a Desktop-only Mac.
- The DMG is checksum-verified after packaging.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
