## dachshund 0.1.15

Agent memory is now easier to understand, and the dachshund landing view is
always one click away.

### Added

- Native memory mechanism diagrams for Codex, WorkBuddy, Claude Code, Claude
  Desktop, OpenCode, Trae, Pi, and Hermes.
- A full-window diagram reader with explicit close and `Escape` behavior.
- Brand-mark navigation to the landing view from both the main app and compact
  menu bar panel.

### Improved

- Rebalanced the landing layout so the agent cloud, primary action, counts, and
  privacy note have clear spacing at the default window size.
- Added a close control and `Escape` handling when the landing is reopened after
  onboarding.
- Kept the existing onboarding state and local memory data intact when returning
  to the landing view.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
