## dachshund 0.1.28

0.1.27 could fail to open for anyone upgrading an existing library. This
release repairs that upgrade path and makes any future startup failure visible
instead of silent.

### Fixed

- Upgrades an existing database before creating the index on
  `superseded_by`. 0.1.27 created that index while the column was still
  missing, so the migration threw and the app quit before drawing a window.
- Writes startup failures to `~/Library/Logs/dachshund/startup-error.log` and
  shows an error dialog with the reason, instead of leaving a windowless
  background process.

### Verified

- A fixture builds a pre-0.1.27 database, opens it through the current schema
  migration, and asserts the legacy row, new columns, and index survive.
- The built app launches against a copy of a real 263-record library, migrates
  it in place, and renders the memory feed.

### Notes

- Existing memories, sources, and settings are preserved; the migration only
  adds columns and indexes.
- If 0.1.27 is already installed and will not open, download this DMG and
  replace the app once. Later updates continue in place.
- The build remains ad-hoc signed and not notarized.
