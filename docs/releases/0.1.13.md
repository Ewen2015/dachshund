## dachshund 0.1.13

Doubao and DeepSeek Harness now use the shared memory library through verified
local MCP connections, while dachshund keeps each agent's native memory boundary
explicit.

### Added

- Verified Doubao MCP connection with all five dachshund memory tools and an
  explicit `doubao` agent identity.
- DeepSeek Harness importer support for surface-aware session events,
  compaction summaries, and user-global `AGENTS.md` rules.
- Managed DeepSeek Harness Cordis connection with an absolute Node.js path and
  `DACHSHUND_CLIENT_AGENT=deepseek-harness`.
- An idempotent shared-memory instruction block in `~/.dsh/AGENTS.md`.

### Improved

- Doubao handshakes are no longer missed when its MCP client reports the generic
  name `rmcp`.
- DeepSeek Harness session logs are decoded one Zstandard frame at a time, so a
  large early frame cannot hide later events.
- Compacted durable cues remain available and are marked `surface-shadowed`
  instead of being presented as current visible context.
- Unchanged DeepSeek Harness sessions reuse an in-process parse snapshot.

### Notes

- Doubao account memory and per-assistant memory remain account-scoped.
- DeepSeek Harness raw sessions and tool output remain evidence; they are not
  imported as memories.
- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
