## dachshund 0.1.26

Claude memory now follows the hierarchy described in Anthropic's
[The components of agent memory](https://www.anthropic.com/research/components-of-agent-memory):
a small injected index, topic notes read on demand, and session transcripts as
ground truth.

### Improved

- Imports Claude Code project and global `MEMORY.md` indexes, plus Claude
  Desktop account, agent, and Space indexes, as `reference` memories tagged
  `memory-index`. Indexes with no entries are skipped.
- Redraws the Claude mechanism diagram and model around the injected index
  (first 200 lines or 25 KB), on-demand topic notes, and transcripts as ground
  truth; offline consolidation (dreaming) is named in the model.
- Adds index, global-memory, and transcript mappings to the Claude page, and
  describes a failed approach, correction, or trap as an insight.
- Renders relative links inside imported Markdown as inert local references
  instead of navigating the app window. External links still open in the
  browser.

### Verified

- Type checks, agent and sync fixtures, panel and outline layout fixtures, and
  the production build pass.
- A read-only scan of the current Mac found three Claude indexes: one repository
  project, one Desktop account, and one Cowork Space.
- The first refresh after upgrading adds the new index records once; later
  refreshes return to `0 memories added · 0 memories updated`.
- The packaged app and its bundled MCP bridge pass the release smoke test.
