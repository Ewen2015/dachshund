## dachshund 0.1.16

The landing view and website now share the same product promise: **All your
agents. One memory.**

### Improved

- Replaced the problem-led landing headline with the solution-focused product
  slogan used by the website.
- Expanded the landing agent constellation to eight representative integrations,
  including WorkBuddy, Hermes, Pi, and DeepSeek Harness.
- Removed the decorative `FIG. 01` label so the agent relationships carry the
  illustration.
- Aligned the landing brand with the native macOS title bar and kept a clear
  34 px gap from the traffic-light controls at supported window widths.
- Kept the English and Chinese website titles, hero copy, footer, and download
  links in sync with the app.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
