## dachshund 0.1.17

This release makes the shared memory library stay current and makes its
classification model easier to understand.

### Added

- Added automatic sync every 60 minutes, with sleep-aware pausing, resume
  catch-up scans, a concurrency guard, and a visible sync result.
- Added source-version tracking so changed files update their existing memory
  instead of creating duplicates; unchanged sources can also be reclassified
  in place without changing their update time.
- Unified TRAE discovery across current and legacy installations, including
  `Trae CN.app`, dynamic MCP configuration paths, and compatibility with older
  configurations.

### Improved

- Separated knowledge `Type` from project `Scope`: WorkBuddy date logs and
  Codex task history remain in History while still exposing their workspace or
  repository scope.
- Extracted only explicit `Reusable knowledge` sections as lessons rather than
  treating every Codex thread as a lesson.
- Added a project scope filter and clearer Type/Scope labels in memory cards and
  details.
- Compressed the sync status bar and balanced its surrounding spacing without
  overlapping memory details.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
