## dachshund 0.1.21

This release fixes the compact menu bar panel in native macOS full-screen
Spaces.

### Fixed

- The menu bar panel now explicitly opts into visibility above full-screen
  windows instead of opening on the underlying desktop Space.
- The workspace behavior is reapplied whenever the panel opens, so it remains
  reliable after the app has been running for a while.
- The panel stays non-fullscreenable, always on top, and available on the
  current display without moving the user away from the active Space.

### Verified

- Added regression coverage for the full-screen workspace options.
- Verified in an isolated Electron run that the panel remains visible and
  focused while the main window is in native full-screen mode.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
