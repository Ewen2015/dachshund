## dachshund 0.1.25

Refresh now reports only what actually changed since the previous scan. A scan
with nothing new reports zero instead of replaying the same update counts.

### Fixed

- A memory echoed by several sources with identical content now keeps the
  presentation of the source that created it. Rescans no longer alternate its
  title, tags, and kind, which previously produced dozens of phantom updates
  every time.
- Codex reusable-knowledge slices stay `insight` instead of being migrated back
  to `task_rollout` on every library read.
- Titles are normalized before comparison, so the Markdown frontmatter round-trip
  no longer counts trailing whitespace as an edit.
- Scan results count unique memories added or updated, not individual import
  operations from multiple sources.

### Improved

- The sync notice and Connectors status always show this refresh's delta,
  including an explicit `0 memories added · 0 memories updated` when nothing
  changed.

### Verified

- Three consecutive scans of a cloned real library report zero additions, zero
  updates, and zero changes.
- Two consecutive manual refreshes in the built app show
  `0 memories added · 0 memories updated`.
- Type checks, sync and agent fixtures, the production build, and the packaged
  MCP bridge pass.

### Notes

- The first scan after upgrading may correct the presentation of existing Codex
  memories once, because the source that created each memory becomes
  authoritative. Later scans settle at zero.
- The build remains ad-hoc signed and not notarized.
