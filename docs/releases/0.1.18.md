## dachshund 0.1.18

This release makes memory counts consistent across the library, Pulse, and
agent views, while reducing the space used by the Agents page.

### Improved

- Pulse now reads a lightweight index of every active memory, so the full
  window and menu bar panel match the complete library rather than the latest
  90 summaries.
- Agent lists now sort by memory count in the data layer, with installed state,
  source count, and name used only as tie breakers.
- Agents rows use a stable single-line description and path layout, smaller
  identity tiles, and tighter controls at the default window size.

### Fixed

- Agent-scoped memory searches apply the agent filter before the result limit,
  so an agent's count and the memories shown after opening it stay aligned.
- The macOS menu bar icon is rendered by a native status-item helper instead of
  an Electron template-image approximation.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
