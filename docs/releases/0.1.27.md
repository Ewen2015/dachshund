## dachshund 0.1.27

Recall now follows the shape that makes Claude's memory index useful: a small
injected index with one-line hooks, a few full notes, and everything else one id
away. The same release makes near-duplicates, missing sources, and credentials
visible instead of silent.

### Improved

- Writes a deterministic one-line summary hook into every record's frontmatter.
  An importer reuses a native `summary` or `description` when one exists;
  otherwise the hook comes from the first meaningful body line. Feeds, search
  results, and MCP recall show the hook before the full text.
- Rebuilds `memory_context` as a bounded index grouped into **Apply**,
  **Context**, and **Background**. Each entry carries its id, kind, scope,
  sources, update date, and project; the first three notes include their body,
  and `detail: "full"` returns every body. The character budget keeps a large
  library from crowding out the conversation.
- Hides archived and superseded records, and excludes Evidence, from default
  search. `includeSuperseded`, `includeEvidence`, `project`, and `scope` are
  explicit opt-ins; a project filter still includes user-scope memories.
- Adds a deterministic consolidation pass for near-duplicates. It groups
  `agent_observed` and `inferred` records by source family or normalized title,
  supersedes near-duplicates behind a canonical note with `superseded_by`, and
  runs at most once per 24 hours once the library has 25 records. A dry run is
  available through `POST /api/consolidate`.
- Marks a record `source_missing` when its agent file disappears from a full
  scan instead of deleting the library copy. Seeing the source again clears the
  mark. Nothing is rewritten in the agent's own files.
- Redacts recognizable credentials on import and rejects credential-looking
  content written through MCP or the local API. Redacted records are tagged
  `redacted-secret`.
- Shows the summary, **Superseded**, and **Source missing** states in the memory
  detail, with a short explanation of what each state means for recall.
- Adds a **Library health** strip to Pulse for superseded echoes, missing
  sources, oversized notes, stale notes, empty `MEMORY.md` indexes, and the last
  consolidation time.
- Keeps each agent's mechanism diagram and taxonomy mapping visible, with
  **Learn more** revealing when memory forms, how it updates, when it is
  recalled, notes, official and community sources, and an evidence label.
- Tightens the layout across the app: compact agent summaries, complete Pulse
  metrics at narrow widths and in the sidebar, a guide diagram that fits, empty
  mapping rows that say "No native equivalent", and a composer that keeps its
  save action visible at 800 x 600.

### Verified

- Type checks, agent, sync, recall, panel, and outline fixtures, the MCP
  integration test, and the production build pass.
- A layout pass covers 46 states at 920 x 700, 800 x 600, sidebar navigation at
  920 x 700, and the 420 x 620 menu bar panel, with no horizontal overflow.
- A read-only import of the current Mac found the existing agent libraries and
  produced no duplicate active records on repeated scans.

### Notes

- Recall and consolidation are deterministic. There is no model call,
  embedding, API key, or network request in either path.
- Consolidation never edits an agent's source file, never deletes library
  content, and keeps every superseded record inspectable.
- The build remains ad-hoc signed and not notarized.
