## dachshund 0.1.23

This release removes the temporary unresolved memory shelf and makes every
durable record land in one of dachshund's four fixed categories.

### Improved

- Removed the **Unclassified** category, status, filter, and `Unclassified` tag
  from every full-app, menu bar, Pulse, agent, Guide, and website surface.
- Reclassified legacy `unknown` and `unclassified` records from their content:
  generic observations become Fact, while paths and source pointers become
  Reference.
- Rewrites legacy library metadata during synchronization, so old Markdown files
  do not keep returning to the removed state.
- Splits Hermes `MEMORY.md` entries by `##` section, allowing profile, project,
  environment, and reference content to be classified independently.
- Keeps the right-side memory inspector from covering the category legend and
  filters in the compact window.
- Synchronized the taxonomy contract, agent mapping, research notes, screenshots,
  README files, and both websites.

### Verified

- Type checks, agent and sync fixtures, outline layout tests, production build,
  MCP integration, panel placement, demo seeding, and screenshot capture pass.
- A real local synchronization completed with 246 active records and zero
  records in the removed category.
- Packaged app launch and the packaged MCP bridge are tested against isolated
  data directories.
- The DMG is checksum-verified after packaging.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
