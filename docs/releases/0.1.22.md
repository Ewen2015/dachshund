## dachshund 0.1.22

This release makes dachshund's memory model visible inside the app and cleans up
the way that model is presented across every memory view.

### Added

- Added a **Guide** tab with a top-down filing plan showing how agent-native
  files become ten durable kinds, then land on one of four fixed categories.
- Added hover, keyboard-focus, and click states to the four category cards so
  one route can be isolated without leaving the guide.
- Documented the mapping from every supported agent's native memory structure
  into dachshund's shared taxonomy.

### Improved

- Consolidated the model into four fixed knowledge categories, ten durable
  kinds, and a separate Evidence layer. The unresolved shelf was removed in the
  subsequent 0.1.x follow-up, with untyped content resolved into an existing
  durable kind.
- Migrated legacy `feedback`, `project`, `episode`, `lesson`, and `workflow`
  values without implying stronger categories than the source supports.
- Synchronized the memory feed, menu bar panel, Pulse, agent views, demo data,
  screenshots, and both websites with the same category order and vocabulary.
- Moved Guide to the final top-level tab and grouped it with Pulse under
  **Insights** when sidebar navigation is enabled.
- Let transient sync notices dismiss after three seconds while preserving the
  hover and keyboard pause needed to read details.
- Added spacing and width safeguards so the Guide diagram, category cards, and
  primary actions remain readable at the compact 800 x 600 window size.

### Verified

- Type checks, agent and sync fixtures, outline layout tests, production build,
  MCP integration, panel placement, demo seeding, and screenshot capture pass.
- Packaged app launch and the packaged MCP bridge are tested against isolated
  data directories.
- The DMG is checksum-verified after packaging.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
