## dachshund 0.1.12

Claude Desktop's local Cowork Space memory now joins the library, and the full
app gains a Magpie-style navigation option.

### Added

- Read-only Claude Desktop import for local Cowork Space topic files, account
  topic files, and agent topic files.
- Shared taxonomy mapping for Claude Desktop `user`, `feedback`, `project`, and
  `reference` memory types.
- Persistent top-tab / sidebar navigation switch with `Cmd+\`.

### Improved

- Sidebar navigation is grouped into Workspace, Insights, and App.
- Pulse lives under Insights.
- Settings is now the Connectors screen, with Agent connections first.
- The sidebar control keeps a clear gap from the macOS window buttons at every
  supported window width.

### Notes

- Claude Desktop's ordinary Chat memory and cloud-only Project memory remain on
  the account; dachshund imports local Space memory and connects the rest over
  MCP.
- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
