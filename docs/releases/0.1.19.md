## dachshund 0.1.19

This release gives dachshund a refreshed identity and makes it easier to read
the structure of long memories and the relationship between agent-native
categories and dachshund's shared taxonomy.

### Added

- Added a collapsible Contents outline to expanded memory details, with active
  section tracking and direct navigation to each heading.
- Added a stable five-category mapping view for every agent. Native categories
  can map many-to-one, and categories without a native equivalent remain
  explicit instead of disappearing.

### Improved

- Replaced the dachshund mark, app icon, menu bar template, website assets, and
  documentation screenshots with the new logo.
- Restored the menu bar mark to a compact 22 x 22 template asset.
- Let sync results dismiss after five seconds while pausing when hovered or
  focused, or while details are expanded.
- Removed the redundant scope filter from the memory feed so category and agent
  filters remain the primary way to browse the library.

### Notes

- Existing installations from `0.1.3` onward can install this update in place
  and relaunch automatically.
- The build remains ad-hoc signed and not notarized.
