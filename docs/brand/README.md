# Brand Assets

- `dachshund-mark.svg`: transparent, current-color silhouette for UI and
  documentation.
- `dachshund-menubar.svg`: 24 x 24 solid black template icon with transparent
  safe margins for the macOS menu bar.
- `dachshund-app-icon.svg`: 1024 x 1024 app icon with a near-white rounded tile.

The mark is original to dachshund. Do not substitute Magpie assets or copy its
wordmark. Keep the negative-space face and body outline readable at 16 to 18 px.
The build renders 22 x 22 and 44 x 44 template PNGs with `contain`, then rejects
either asset if visible pixels touch an edge.
