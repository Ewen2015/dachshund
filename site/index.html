05 / A model you can inspect

Every memory has one place.

Guide explains the filing model in plain language. Agent-native files become ten durable kinds, then land on one of four fixed shelves. Evidence stays in a separate review tray, while untyped imports resolve into an existing durable shelf.

06 / Ambient, not in the way

One shortcut from thought to memory.

dachshund lives in the macOS menu bar. Search what your agents know, glance at recent echoes, or write a shared memory without opening a second workspace. The panel opens on your current display and stays above the Space you are using. In the full app, keep navigation in the top bar or switch to a Magpie-style sidebar.

07 / MCP without a cloud layer

Memory that travels with the question.

Once connected, any agent can search, request a prompt-ready context block, write a durable memory, archive a shared copy, and inspect the library. MCP initialization and managed agent instructions tell clients when to ask for shared context before they answer.

memory_search

Find the right context

Search the local library and keep source provenance attached to every result.

→ query in, sources out
memory_context

Build a prompt block

Return a compact context block that is ready to place in front of an agent.

→ relevant, not exhaustive
memory_remember

Write once

Keep the calling agent as provenance. Identical content from another agent becomes a second source, not a duplicate note.

→ attributable + deduplicated
memory_forget

Archive the shared copy

Remove a memory from the shared library without deleting the agent's original file.

→ source stays intact
memory_stats

Inspect the library

See memory, agent, source and echo counts before an agent starts working.

→ grounded in what exists

No hosted dependency

The bridge runs over loopback and uses a short-lived token held in an owner-only runtime file.

08 / Local by architecture

Your memory does not leave this Mac.

This is not a privacy setting. There is no hosted memory layer to switch off. The files, index, and MCP service stay on your machine.
