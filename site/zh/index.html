05 / 常驻，但不打扰

从想到一件事，到记下来，只差一个快捷键。

dachshund 住在 macOS 菜单栏。搜索 Agent 已经知道的内容、看一眼最近的跨 Agent 回声，或写下一条共享记忆，不用再打开第二个工作区。面板会在当前屏幕打开，并停留在你正在使用的 Space 上方。完整应用可以在顶部 tab 与 Magpie 式侧边栏之间切换

⌘ ⇧ D
打开或关闭紧凑面板
⌘ ⇧ M
最小化到菜单栏
⌘ K
搜索全部记忆
⌘ \
切换顶部 tab 与侧边栏

06 / 不经过云端的 MCP

让记忆跟着问题一起出现。

连接后，任何 Agent 都可以搜索记忆、请求可直接放进 Prompt 的上下文块、写入持久记忆、归档共享副本，并查看记忆库统计。MCP 初始化和托管指令会告诉 Agent：在问题依赖既有上下文时，先查询共享记忆

memory_search

找到正确上下文

搜索本地记忆库，每条结果都保留来源信息

→ 输入问题，返回来源
memory_context

生成 Prompt 块

返回一段紧凑、可直接交给 Agent 使用的上下文

→ 相关，而不是全量
memory_remember

只写一次

保留调用方 Agent。另一个 Agent 写入完全相同的内容时，只增加来源，不生成重复笔记

→ 来源可追，内容去重
memory_forget

归档共享副本

从共享记忆库移除，但不删除 Agent 自己的原始文件

→ 原始文件不动
memory_stats

查看记忆库

在 Agent 开始工作前，先看记忆、Agent、来源和回声数量

→ 只基于已经存在的内容

没有托管依赖

Bridge 只通过回环地址运行，短期 Token 保存于仅当前用户可读的运行时文件

07 / 本地是架构，不是开关

你的记忆，不会离开这台 Mac。

没有一个可以关掉的托管记忆层。文件、索引和 MCP 服务都留在这台电脑上
